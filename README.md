# 🎴 3D UNO — Telegram Mini App Game (RU / UZ)

Полноценный реалистичный 3D-симулятор настольной игры **UNO** для Telegram-групп и Telegram Mini Apps (Web Apps) с поддержкой мультиплеера в реальном времени (Socket.io), умных AI-ботов, физики 3D-стола от первого лица (POV) и двуязычным интерфейсом (Русский / O'zbekcha).

## ✨ Возможности
- **Реалистичный 3D POV-стол**: Перспектива от первого лица, зеленое/неоновое казино-сукно, 3D-анимация переворота и броска карт, веер карт в руке.
- **Все официальные карты и правила UNO**:
  - Цифры `0–9` четырех цветов (Красный, Желтый, Зеленый, Синий)
  - `🚫 Пропуск хода` (Skip)
  - `🔄 Разворот направления` (Reverse)
  - `+2 Возьми две` (Draw Two)
  - `🌈 Заказ цвета` (Wild)
  - `+4 Заказ цвета и возьми четыре` (Wild Draw Four)
- **Кнопка "UNO!" и кнопка "ПОЙМАТЬ! (+2)"**: Если у игрока осталась 1 карта и он не успел нажать `UNO!`, любой участник чата может нажать `Поймать!` и выдать ему 2 штрафные карты.
- **Синхронизация комнат для Telegram-групп**: Автоматический вход в комнату группы через параметр `?room=chat_123` или `startapp` из Telegram.
- **Встроенная поддержка `/startgame` и генератор ссылки для группы**: Работает как напрямую по ссылке Mini App, так и через Telegram-бота.
- **Эндпоинт `/ping`**: Для UptimeRobot и Cron-job.org, чтобы сервер на Render никогда не засыпал.
